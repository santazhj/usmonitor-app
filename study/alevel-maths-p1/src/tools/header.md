**List of formulae** (as provided in the examination)

*Quadratic equation:* for $ax^2+bx+c=0$, $\;x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$

*Binomial expansion:* $(a+b)^n = a^n + \binom{n}{1}a^{n-1}b + \binom{n}{2}a^{n-2}b^2 + \dots + b^n$, where $\binom{n}{r} = \dfrac{n!}{r!\,(n-r)!}$

*Arithmetic series:* $u_n = a+(n-1)d,\quad S_n = \tfrac12 n(a+l) = \tfrac12 n\{2a+(n-1)d\}$

*Geometric series:* $u_n = ar^{n-1},\quad S_n = \dfrac{a(1-r^n)}{1-r}\ (r\ne1),\quad S_\infty = \dfrac{a}{1-r}\ (|r|<1)$

*Circular measure:* arc length $= r\theta$, sector area $= \tfrac12 r^2\theta$ ($\theta$ in radians)

*Trigonometry:* $\tan\theta \equiv \dfrac{\sin\theta}{\cos\theta},\quad \sin^2\theta+\cos^2\theta\equiv1$

*Differentiation and integration:* $\dfrac{d}{dx}(x^n)=nx^{n-1},\quad \displaystyle\int x^n\,dx = \frac{x^{n+1}}{n+1}+c\ (n\ne-1)$
